🌍 Worldwide Demographic Dashboard – Power BI

📌 Project Overview

This project analyzes global demographic data using Power BI.
The dashboard provides insights into population distribution, life expectancy, languages, and GNP per capita across different countries and continents.

📂 Datasets Used

city.csv – City-wise demographic details

country.csv – Country-level population, GNP, and life expectancy

language.csv – Language distribution across countries

🔍 Key Insights

Global KPIs: Cities, Countries, Languages, Population

Population distribution by continent & country

Life Expectancy vs GNP per capita analysis

Drill-through analysis for continent-level insights

Interactive map visuals for geographic exploration

🛠️ Skills & Tools

Power BI – Data modeling, KPIs, DAX, and visualization

SQL/Python – Data cleaning and preparation

Storytelling with Data – Creating meaningful insights
